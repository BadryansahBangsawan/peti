# Peti canvas redesign

Scope: editable desktop app design in `../untitled.pen`. Mode: Operate. Source application is inspected, not modified.

## Direction contract

THESIS: Make the repository and its next action the center of the interface. Navigation, transfer status and local destination remain explicit.

OWN-WORLD: Solid white/cool neutral surfaces, graphite controls, Geist UI type and the original Slot symbol. Muted green and red communicate status with text. Quiet boundaries and spacing replace decoration.

STORY: Paste or discover a repository, choose the action and folder, follow its queue state, then open the local result. Fork is always an explicit choice.

FIRST VIEWPORT: Downloads uses a 220 px sidebar, 66 px toolbar and a single main column containing the title/action, paste field, live summary, status tabs and repository rows. Each row owns its controls. Compact 1100 × 800 uses a 72 px icon rail.

FORM: Native editable Pen.dev frames, text, icons, original logo geometry and reusable controls. The user-supplied pen.dev workflow is authoritative. Mobbin references inform task patterns rather than copying branding. No raster comp or implementation code is produced.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## References inspected via MCP Mobbin

- [Proton transfer list](https://mobbin.com/screens/218d53af-5262-4a58-ba33-150cf786437b): per-item progress/status and actions.
- [Sana search](https://mobbin.com/screens/b0dd48a9-7f85-4322-8592-f673a14309f7): search, compact filter chips and readable result rows.
- [Relevance AI task filters](https://mobbin.com/screens/11dc1da7-db6d-4887-8f2e-13916ca07ed8): sidebar hierarchy and status filtering.

All exported PNGs are renders of the authored editable canvas, not generated or sourced artwork. The logo reuses the exact path geometry from the repository SVG; lucide supplies icons. Mock names, metrics, dates, paths and codes are illustrative and labelled in the screens.

## Continuation scope

The user requested the missing pages be continued. The visual world and existing product scope are preserved. Twelve added screens turn transfer detail/completion/failure, filtered search, first use, empty Library, guest Settings and fork result into full-page compositions, then complete dark variants for Home, Discover, Library and Settings. No new product domain or navigation destination is introduced. Original core pages remain in place; new pages are grouped below the state boards.
